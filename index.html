🛠️ 大廳與連線 (Builder & Network)

  • 牌組管理：可透過大廳選項「新增、命名、切換、清空」多套牌組。
  • 快速匯入：點擊「一鍵匯入」，貼上卡片編號（以逗號或空白分隔），可快速匯入未收錄的卡片。
  • 邀請對手：點擊左上角黃色的「你的 ID」，即可複製邀請連結，傳給對手即可一鍵連線。
  • 列印代牌：點擊大廳的「🖨️ 列印代牌」將自動排版為 63x88mm 的 A4 格式，列印時請確保「縮放比例」為 100% 或預設。

🖱️ 基礎操作 (對戰中)

  • 移動卡片：直接拖曳卡片到任何區域。拖曳放回牌組時，會跳出「置頂/置底」選單。
  • 疊牌拖曳：對著場上的卡片長按不放（約0.3秒）直到發出黃光，即可將整疊卡片一起拖曳。
  • 橫置 / 直立：單擊卡片。
  • 翻面：手機上可透過快速雙擊卡片翻面。
  • 檢索區域：對著「牌組、生命區、場外、移除區、場上卡槽」點擊右鍵（手機為長按），即可開啟彈出視窗，查看或檢索裡面的卡片。
  • 調整 BP：點擊前線卡槽右下角的「⚔️ BP」標籤，即可開啟數值增減面板。

⌨️ 快捷鍵 & 👆 觸控面板操作

  • 電腦版玩家：將滑鼠懸停於卡片上，並按下對應鍵盤按鍵。
  • 平板 / 手機版玩家：先點擊卡片選取（卡片會亮起綠框），再點擊畫面左側的觸控面板按鈕執行動作。
F 或 面板：翻面
R 或 面板：橫置 / 洗牌
T / B 或 面板：放回牌組 頂 / 底
C 或 面板：移至手牌
V 或 面板：移至場外
G 或 面板：移至檢索區
N 或 面板：移至移除區
D 或 面板：抽一張牌
Space：結束回合

🌐 系統與防作弊

  • 對戰聊天室：點擊畫面左上角的 💬 開啟。
  • 系統播報：當你或對手將卡片放回牌組（置頂或置底）時，不論是從手牌、場上或檢索區移入，系統都會自動在聊天室發送公播訊息，確保雙方資訊透明。
  • 視角控制：右下角按鈕可切換 3D/2D 視角、縮放畫面（也可使用滑鼠滾輪），點擊空白處拖曳可平移視角。
